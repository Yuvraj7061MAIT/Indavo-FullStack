This is the frontend part of our Fashion & Lifestyle Store, built with React and Tailwind CSS to provide a smooth and responsive shopping experience. 🛍️

🚀 Features
Responsive UI: Fully adaptable to different screen sizes.
Product Grid: Displays all products with current prices and discounts.
Navigation: Links to different pages such as the product page and offers.
Hero Section: Showcasing new arrivals and exclusive offers.
🛠️ Technologies Used
React.js for building the user interface.
Tailwind CSS for quick and efficient styling.
React Router for page navigation.
